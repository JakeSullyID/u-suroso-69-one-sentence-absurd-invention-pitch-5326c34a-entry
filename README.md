# One-Sentence Absurd Invention Pitch

This entry is a Node 22 program that writes a single absurd-invention pitch sentence to entry.txt, deterministic, no network, no dependencies. It outlines an over-engineered mechanical defense mechanism designed to solve a trivial daily inconvenience. Crafting a single razor-sharp sentence is the ultimate test of comedic punch and conciseness for this challenge.

## How to Run

To run the program and generate the output file, execute:

```bash
node main.ts
```

You can specify a custom output directory by setting the `MAKEFUN_OUTPUT_DIR` environment variable:

```bash
MAKEFUN_OUTPUT_DIR=./custom-output node main.ts
```
